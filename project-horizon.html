Horizon Club Website

View Live Project
View Project Repository

The Horizon Club New Website is a modern, responsive website created to serve as the official online presence of Horizon Club. It showcases the club’s mission, activities, events, and community impact while providing visitors with clear navigation and an easy way to learn about and join the club.

Horizon Club previously lacked a centralized and professional digital platform to present its identity, highlight its events, and engage potential members, which limited visibility and outreach within the student and tech community.

The project delivered a clean, responsive, multi-page website built with a structured front-end design that clearly communicates the club’s vision, promotes activities and events, integrates social links, and encourages new members to join—all deployed and maintained via GitHub Pages.

Key Technical Features

  • Responsive Multi-Page Design
  • Clean Navigation Structure
  • Static Hosting via GitHub Pages
  • Club Identity & Event Content Integration
  • Social & Contact Link Integration
  • Separation of Styles & Layouts
